# RailNav

Ayuda de consulta para maquinistas en líneas sin ERTMS: lee la hoja de ruta y el documento
semanal de limitaciones temporales de velocidad (DLTV) de ADIF, los cruza y muestra la
marcha en una pantalla de estilo DMI.

**Servicio no oficial ni homologado por la AESF.** Es una herramienta de estudio y consulta;
no sustituye a la documentación oficial ni a la señalización.

- Aplicación web instalable (PWA) pensada para iPad: Safari → Compartir → «Añadir a pantalla
  de inicio». Funciona sin conexión.
- Los PDF se leen en el propio dispositivo y no se envían a ningún sitio. Este repositorio no
  contiene documentos de ADIF; la ruta de demostración es sintética.
- Lectura de PDF con [pdf.js](https://mozilla.github.io/pdf.js/) (Apache 2.0, ver
  `vendor/pdfjs/LICENSE`).

  uso, privacidad y contacto).
